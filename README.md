# Data Analyst Internship – Task 1

## Data Cleaning and Preprocessing

### 📌 Objective

The objective of this task was to clean and preprocess the **Customer Personality Analysis** dataset and prepare it for further analysis.

### 🛠 Tools Used

* Python
* Pandas
* Google Colab
* GitHub

### 📂 Dataset

**Customer Personality Analysis**

The dataset contains customer demographic information, purchasing behaviour, campaign responses, and other customer-related attributes.

### 🔧 Data Cleaning Steps Performed

1. **Loaded the dataset** using Pandas.
2. **Inspected the dataset** by checking columns, data types, and basic information.
3. **Checked for missing values** and handled the identified missing/invalid values.
4. **Checked for duplicate records** and removed duplicates where required.
5. **Standardized categorical values**, including Education and Marital Status, by identifying inconsistent categories.
6. **Checked and corrected data types** for numerical and categorical columns.
7. **Checked the cleaned dataset** to ensure the data was consistent and ready for analysis.
8. Saved the final cleaned dataset as `cleaned_customer_personality.csv`.

### 📊 Key Data Quality Checks

The following checks were performed:

* Missing values
* Duplicate records
* Inconsistent categorical values
* Column names
* Data types
* Overall data consistency

### 📁 Files Included

* `marketing_campaign.csv` – Original/raw dataset
* `cleaned_customer_personality.csv` – Cleaned dataset
* `Task 1 - Data Cleaning and Preprocessing.docx` – Task instructions/documentation
* `README.md` – Project description and cleaning summary

### ✅ Outcome

The raw customer dataset was cleaned and structured using Python and Pandas. The resulting dataset is ready for further **data analysis and visualization**.
